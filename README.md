# LUXE JEWELS

A responsive luxury jewellery storefront demo built with HTML, CSS, and JavaScript.

## Project Structure

- `index.html` – home page
- `products.html` – shop and filtering page
- `product-details.html` – product detail page
- `login.html` – user login
- `register.html` – registration page
- `cart.html` – shopping cart
- `checkout.html` – delivery and payment form
- `order-confirmation.html` – order success confirmation
- `css/` – styling files
- `js/` – app logic
- `images/` – sample jewellery image folders

## Features

- Premium luxury storefront design
- Product catalog with 12 sample products
- Search, category, price, and rating filters
- Product detail view with quantity selection
- Wishlist support using localStorage
- Cart management and checkout flow
- Demo login and registration validation
- Demo payment flow and order confirmation
- Responsive mobile menu and modern styling

## Demo Notes

- This is not a real payment processor or production authentication system.
- All customer-related data is stored in browser LocalStorage for demo purposes only.

## How to Run

1. Open the project folder in VS Code.
2. Launch a local web server or use Live Server extension.
3. Open `index.html` in the browser.

Example with Python:

```bash
cd LUXE-JEWELS
python3 -m http.server 8000
```

Then open: http://localhost:8000
